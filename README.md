# New York Voter Turnout and Lead Contamination

🔗 **Live Demo:**
https://owendev225.github.io/New-York-Map-Voter-Turnout-and-Lead-Contamination-/

## Overview

This project is an interactive map that visualizes voter turnout and lead contamination across New York communities. By combining environmental and civic data, it allows users to explore how public health challenges and political participation may intersect at the local level.

## Why I Built This

I wanted to make complex public-interest data more accessible and easier to explore. Environmental health and civic engagement are often discussed separately, despite both shaping community well-being. This project brings those datasets together in a single visualization, helping users identify patterns, ask questions, and draw their own conclusions.

## Features

* Interactive map of New York communities
* Visualization of voter turnout and lead contamination data
* Accessible presentation of public-interest datasets


## Key Takeaways

Building this project reinforced an important lesson: data alone is rarely enough. Information becomes meaningful when it is presented in a way that invites exploration and understanding. My goal was not simply to display data, but to create a tool that helps people engage with it.
